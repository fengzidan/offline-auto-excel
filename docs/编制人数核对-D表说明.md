# 人力分析 · D 表说明与方案导入

可导入方案文件：`schemes/人力分析.json`（应用内点 **导入方案**）。

## D 表推荐表头（长表，一行=一档×一岗位）

| 规模档次 | 保费下限（万） | 保费上限（万） | 岗位 | 编制人数 |
| --- | --- | --- | --- | --- |
| 5000万以下 | 0 | 5000 | 销售内勤 | 3 |
| 5000万以下 | 0 | 5000 | 理赔 | 2 |
| 5000-10000万 | 5000 | 10000 | 销售内勤 | 5 |
| 5000-10000万 | 5000 | 10000 | 理赔 | 3 |
| 10000万及以上 | 10000 | 999999 | 销售内勤 | 8 |
| 10000万及以上 | 10000 | 999999 | 理赔 | 4 |

- **规模档次**：须与方案第 7 步公式文案一致。
- **保费下限/上限**：便于人工维护；匹配按「规模档次」+「岗位」。
- **岗位**：与人员清单「岗位」一致。

## 源表文件名（须与方案内 `src:…` 一致）

| 角色 | 文件名（不含扩展名） | 表头要点 |
| --- | --- | --- |
| A | 人员清单 | 员工工号、中心（或机构）、一级部、岗位… |
| B | 分公司下发编制 | 部门、岗位、总公司下发编制 |
| C | 中支保费 | 机构、今年保费计划（万）、去年保费收入（万） |
| D | 规模编制对照 | 如上 |

人员清单默认用 **「中心」** 作机构列；若实际是「机构」，导入后在相关步骤里改列名。

## 使用

1. **导入方案** → 选择 `schemes/人力分析.json`。
2. 选择含上述四个 xlsx 的源文件夹。
3. 核对步骤后保存并执行生成。
